Moving to Figma

Try dragging the SVGs onto the canvas. Import has not been tested here. Whether text stays editable depends on the importer. Create variables, Auto Layout, component variants, and prototype links separately in Figma. The JSON file is a reference, not a plugin-specific format.

This is an initial proposal, not a copy of the Figma file we could not access. The dark theme covers foundations and the call panel, not the full library. Examples do not cover every state. Incoming call and connection recovery behaviors are requirements for future work, not verified app features.

For larger text, increase row height and use fewer control columns. VoiceOver order: caller, status, controls, end call. When muted, change the action label to “Unmute” and announce “Microphone muted”. Account for system safe areas when building the app. Icons are original vector sketches.
